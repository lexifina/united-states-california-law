# California Public Resources Code § 5097.997

For the purposes of this chapter, the following terms have the following meanings:

- (a) “ Heritage center” means the California Indian Heritage Center.

- (b) “Task force” means the California Indian Heritage Center Task Force as described in Section 5097.998.

Source: Added by renumbering Section 5097.993 by Stats. 2004, Ch. 286, Sec. 7. Effective January 1, 2005.
