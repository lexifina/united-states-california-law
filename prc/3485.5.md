# California Public Resources Code § 3485.5

The following criteria shall be used to evaluate grant applications:

- (a) The need for a used oil collection project within a jurisdiction.

- (b) The commitment of local agency funds to the used oil collection project.

- (c) The commitment of the local agency to continue the used oil collection project after state funding has expired.

- (d) The consideration given to a curbside used oil collection program.

Source: Added by Stats. 1990, Ch. 1657, Sec. 2.
