# California Public Resources Code § 26569.1

At any time no later than the time set for hearing, any owner of real property within the proposed district may file with the clerk, a written protest to the formation of the district. A written protest shall contain a description of the land by lot, tract, and map number and shall be signed by the owner.

Source: Added by Stats. 1984, Ch. 555, Sec. 2. Effective July 18, 1984.
