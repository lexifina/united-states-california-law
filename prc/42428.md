# California Public Resources Code § 42428

If another state implements a covered battery recycling program, a program operator may, consistent with the requirements of this chapter, collaborate with that state to conserve resources necessary to efficiently manage and implement the program operator’s stewardship program in this state.

Source: Added by Stats. 2022, Ch. 351, Sec. 1. (AB 2440) Effective January 1, 2023.
