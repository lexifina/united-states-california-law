# California Public Resources Code § 42557

On and after January 1, 1995, all telephone directories distributed within the state shall be made from materials that will allow for the maximum volume of directories to be recycled, as determined by the board. If reasonably feasible, it is the goal of this state that existing waste paper recyclers make an effort to accept telephone directories for recycling.

Source: Added by Stats. 1991, Ch. 1066, Sec. 2. Section (as part of Article 2) conditionally operative as prescribed in Section 42553.
