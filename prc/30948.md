# California Public Resources Code § 30948

Consistent with Section 30947, the board shall establish an accelerated selection and contracting procedure for projects that meet all of the following criteria:

- (a) The project is part of an approved watershed management plan consistent with Section 30947.

- (b) The project is fully permitted and ready to be implemented.

- (c) Funding for the project includes matching funds or services donated from nonstate sources.

Source: Added by Stats. 2002, Ch. 727, Sec. 1. Effective January 1, 2003.
