# California Welfare and Institutions Code § 4880

Notwithstanding any other law, moneys in, contributions to, and any distribution for qualified disability expenses from, an ABLE account, not to exceed one hundred thousand dollars ($100,000), shall not count toward determining eligibility for a state or local means-tested program.

Source: Added by Stats. 2015, Ch. 774, Sec. 6. Effective January 1, 2016.
