# California Welfare and Institutions Code § 4100

The department has jurisdiction over the following hospitals:

- (a) Atascadero State Hospital.

- (b) Coalinga State Hospital.

- (c) Metropolitan State Hospital.

- (d) Napa State Hospital.

- (e) Patton State Hospital.

- (f) Any other State Department of State Hospitals facility subject to available funding by the Legislature.

Source: Amended by Stats. 2014, Ch. 718, Sec. 3. Effective January 1, 2015.
