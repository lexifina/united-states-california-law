# California Welfare and Institutions Code § 7500

There are established in the state the following state hospitals for the care and treatment of persons with developmental disabilities:

- (a) Sonoma State Hospital, in Sonoma County.

- (b) Lanterman State Hospital, in Los Angeles County.

- (c) Porterville State Hospital, in Tulare County.

- (d) Fairview State Hospital, in Orange County.

Source: Amended by Stats. 2014, Ch. 144, Sec. 132. (AB 1847) Effective January 1, 2015.
