# California Health and Safety Code § 18916

“Model code” means any building code drafted by private organizations or otherwise, and shall include, but not be limited to, the latest edition of the following:

- (a) The International Building Code of the International Code Council.

- (b) The Uniform Plumbing Code of the International Association of Plumbing and Mechanical Officials.

- (c) The Uniform Mechanical Code of the International Association of Plumbing and Mechanical Officials.

- (d) The National Electrical Code of the National Fire Protection Association.

- (e) The International Fire Code of the International Code Council.

- (f) The International Existing Building Code of the International Code Council.

- (g) The International Residential Code of the International Code Council.

Source: Amended by Stats. 2017, Ch. 418, Sec. 2. (AB 1714) Effective January 1, 2018.
