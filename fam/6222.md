# California Family Code § 6222

There is no filing fee for an application, a responsive pleading, or an order to show cause that seeks to obtain, modify, or enforce a protective order or other order authorized by this division when the request for the other order is necessary to obtain or give effect to a protective order. There is no fee for a subpoena filed in connection with that application, responsive pleading, or order to show cause.

Source: Amended by Stats. 2006, Ch. 476, Sec. 3. Effective January 1, 2007.
