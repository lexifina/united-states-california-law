# California Education Code § 18339

Every library district shall be designated by the name and style of “\_\_\_\_ Library District (using the name of the district) of \_\_\_\_ County (using the name of the county in which the district is situated).” The governing board of library trustees may select a name which sufficiently distinguishes the library district from an existing school district. A number shall not be used as a part of the designation of any library district.

Source: Amended by Stats. 2005, Ch. 27, Sec. 1. Effective June 30, 2005.
