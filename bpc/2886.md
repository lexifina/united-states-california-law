# California Business and Professions Code § 2886

- (a) It is unlawful for a person to willfully make any false representation or to impersonate any other person in connection with any examination or application for a license, or request to be examined or licensed.

- (b) It is unlawful for a person to permit or aid any person in any manner to impersonate that person in connection with any examination or application for a license, or request to be examined or licensed.

Source: Amended by Stats. 2022, Ch. 28, Sec. 3. (SB 1380) Effective January 1, 2023.
