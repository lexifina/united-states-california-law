# California Business and Professions Code § 22757.5

- (a) This chapter does not apply to any product, service, internet website, or application that provides exclusively non-user-generated videogames.

- (b) Before January 1, 2029, this chapter does not apply to a GenAI system that is designed to primarily function as assistive technology.

Source: Amended by Stats. 2026, Ch. 861, Sec. 7. (SB 1000) Effective September 30, 2026.
