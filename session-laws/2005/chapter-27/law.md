# Stats. 2005, ch. 27 (AB 796)

The people of the State of California do enact as follows:SECTION 1.Section 18339 of the Education Code is amended to read:18339.Every library district shall be designated by the name and style of “____ Library District (using the name of the district) of ____ County (using the name of the county in which the district is situated).” The governing board of library trustees may select a name which sufficiently distinguishes the library district from an existing school district. A number shall not be used as a part of the designation of any library district.
