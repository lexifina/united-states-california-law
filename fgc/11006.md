# California Fish and Game Code § 11006

The following constitutes Fish and Game District 2 1/4:

Lake County and the waters of Clear Lake.

Any reference in this code to Clear Lake refers to District 2 1/4.

Except as otherwise provided, all of the provisions of this code relating to District 2 apply to District 2 1/4.

Source: Enacted by Stats. 1957, Ch. 456.
