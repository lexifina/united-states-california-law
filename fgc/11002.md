# California Fish and Game Code § 11002

The following constitutes Fish and Game District 1 3/8:

Those portions of the following counties not included in other districts: Alpine, El Dorado, Amador, Calaveras, Tuolumne and Mariposa.

Except as otherwise provided, all of the provisions of this code relating to District 1 shall apply to District 1 3/8.

Source: Enacted by Stats. 1957, Ch. 456.
