# California Fish and Game Code § 11009

The following constitutes Fish and Game District 3 1/2:

Those portions of the following counties not included in other districts: San Luis Obispo, Santa Barbara, Ventura, and Kern.

Except as otherwise provided all of the provisions of this code applicable to District 3 apply to District 3 1/2.

Source: Enacted by Stats. 1957, Ch. 456.
