# California Fish and Game Code § 10820

- (a) The areas described in this article are game refuges.

- (b) An existing reference to a “Fish and Game District” that is a game refuge shall be construed to refer to the “Game Refuge” that continues the former district.

Source: Amended by Stats. 2023, Ch. 132, Sec. 185. (AB 1760) Effective January 1, 2024.
