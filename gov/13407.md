# California Government Code § 13407

Because a risk management system and internal control, including ongoing monitoring, inhibit resource waste and thereby create savings, the fiscal effect of this chapter should be minor and manageable, therefore, state entities shall implement the provisions of this chapter by using existing resources.

Source: Repealed and added by Stats. 2026, Ch. 255, Sec. 12. (AB 184) Effective September 18, 2026.
