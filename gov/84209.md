# California Government Code § 84209

A candidate or state measure proponent and any committee or committees which the candidate or a state measure proponent controls may file consolidated campaign reports under this chapter. Such consolidated reports shall be filed in each place each of the committees and the candidate or state measure proponent would be required to file campaign reports if separate reports were filed.

Source: Amended by Stats. 2025, Ch. 278, Sec. 32. (AB 808) Effective January 1, 2026. Conditionally operative pursuant to Sec. 78 of Stats. 2025, Ch. 278.
