# California Government Code § 29825

The treasurer shall maintain a separate register for registered warrants that records for each registered warrant all of the following information:

- (a) The date on which the warrant is presented.

- (b) The rate of interest payable on that warrant.

- (c) Any specified maturity date of that warrant.

Source: Repealed and added by Stats. 1993, Ch. 1187, Sec. 15. Effective January 1, 1994.
