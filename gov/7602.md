# California Government Code § 7602

A state agency which is authorized pursuant to Section 22312 of the Education Code and Sections 16481 and 20208.5 of the Government Code may enter into security loan agreements with broker-dealers and with any state or national banks for the purpose of prudently supplementing the income normally received from investments.

Source: Amended by Stats. 1982, Ch. 1194, Sec. 3.
