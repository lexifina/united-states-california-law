# California Government Code § 20483

If all members of the local system become members of this system, the operation of the local system shall be discontinued as of the date provided for in the contract, and if only a part of the members become members of this system, the operation of the local system shall be so discontinued with respect to that part.

Source: Added by Stats. 1995, Ch. 379, Sec. 2. Effective January 1, 1996.
