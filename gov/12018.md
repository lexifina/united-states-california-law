# California Government Code § 12018

Except as otherwise provided by statute, the Governor may designate which single state agency shall be responsible for each federal program in which federal money is given to the state with the requirement that it be handled by a single state agency.

Whenever the Governor designates an agency pursuant to this section, he shall notify the Joint Legislative Budget Committee of the agency designated and the federal program for which such agency was designated.

Source: Added by Stats. 1970, Ch. 1073.
