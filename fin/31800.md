# California Financial Code § 31800

It shall be unlawful for any person willfully to make any untrue statement of a material fact in any application or report filed with the commissioner under this division or under any regulation or order issued under this division, or willfully to omit to state in any such application or report any material fact which is required to be stated therein.

Source: Amended by Stats. 1996, Ch. 1064, Sec. 694. Effective January 1, 1997. Operative July 1, 1997.
