# California Elections Code § 2108

The county elections official shall keep and maintain a current file listing all persons appointed or deputized by the county elections official to register voters, which file shall be open to public inspection. The file shall include the party affiliation, if any, of each person listed.

Source: Enacted by Stats. 1994, Ch. 920, Sec. 2. Repealed by Stats. 2015, Ch. 728, upon satisfaction of condition in Sec. 88.
