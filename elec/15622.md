# California Elections Code § 15622

The request may specify the order in which votes are recounted by precinct or by the batch in which the ballots were scanned. In the case of a recount that includes more than one county, the request may specify the order that counties will conduct the recount within the jurisdiction.

Source: Amended by Stats. 2025, Ch. 282, Sec. 4. (AB 930) Effective January 1, 2026.
