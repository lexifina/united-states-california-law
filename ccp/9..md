# California Code of Civil Procedure § [9.]

Section Nine. When a limitation or period of time prescribed in any existing statute for acquiring a right or barring a remedy, or for any other purpose, has begun to run before this Code goes into effect, and the same or any limitation is prescribed in this Code, the time which has already run shall be deemed part of the time prescribed as such limitation by this Code.

Source: Amended by Code Amendments 1873-74, Ch. 383.
