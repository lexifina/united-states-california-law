# California Food and Agricultural Code § 54443

The advisory committee shall study and report on all of the following issues:

- (a) Unfair trade practices.

- (b) Licensing.

- (c) Funding.

- (d) Investigation and hearing procedures.

- (e) The need for a mechanism to resolve bargaining disputes.

- (f) Any other issues relating to this chapter.

- (g) Any recommended changes to this chapter.

Source: Added by Stats. 2005, Ch. 613, Sec. 2. Effective January 1, 2006.
