# California Water Code § 8817

The assessors may also in the assessment list for any county make use of other abbreviations, if a schedule and explanation thereof with reasonable certainty is, unless printed on each page of the assessment list, prefixed to the assessment list and a reference thereto written, printed or stamped on each page of the assessment list whereon any such abbreviation is used.

Source: Added by Stats. 1943, Ch. 369.
