# California Water Code § 78530

- (a) There is hereby created in the account the Central Valley Project Improvement Subaccount.

- (b) For the purposes of this article, “subaccount” means the Central Valley Project Improvement Subaccount created by subdivision (a).

Source: Added by Stats. 1996, Ch. 135, Sec. 1. Approved in Proposition 204 at the November 5, 1996, election.
