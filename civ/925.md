# California Civil Code § 925

If the builder fails to complete the repair within the time specified in the repair plan, the claimant is released from the requirements of this chapter and may proceed with the filing of an action. If this occurs, the standards set forth in the other chapters of this title shall continue to apply to the action.

Source: Added by Stats. 2002, Ch. 722, Sec. 3. Effective January 1, 2003.
