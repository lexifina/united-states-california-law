# California Civil Code § 924

If the builder elects to repair some, but not all of, the claimed unmet standards, the builder shall, at the same time it makes its offer, set forth with particularity in writing the reasons, and the support for those reasons, for not repairing all claimed unmet standards.

Source: Added by Stats. 2002, Ch. 722, Sec. 3. Effective January 1, 2003.
